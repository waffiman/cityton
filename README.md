# City-Ton Austria — Corporate Website (Premium rebuild)

Bilingual (DE/EN) corporate website for City-Ton Austria — professional window-film installation in partnership with Armolan Europe and LLumar.

## Stack

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4
- next-intl 4 (manual DE/EN switcher)
- Pure SVG infographics
- Resend for form email (optional)

## Getting started

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) (port 3001 avoids a local Postgres conflict on 3000).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Development server on port 3001 |
| `npm run build` | Production build |
| `npm run start` | Serve production build |
| `npm run lint` | ESLint |
